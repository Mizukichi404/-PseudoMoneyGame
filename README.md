# スワイプ成金

札を無限に弾いて、ゲーム内の円を稼ぐゲームです。現実のお金にはなりません。

## 遊び方

- 札をドラッグしてはじく。下のボタン、または矢印キーでも弾ける。
- **右 · 即金** — その場で受け取る。
- **左 · 交渉** — うまくいけば跳ねる。失敗すると薄い。
- **上 · 長期** — 数枚あとで、まとめて入る。
- **下 · 見送り** — 少額。コンボは残る。罠はこれで避ける。
- 速く弾くと増額。間を空けずに続けるとコンボが太る。
- 「特価」の札は話がうますぎる。右で掴むと損。
- 店で指さばき、商才、眼力、看板、敏腕秘書を買う。
- 秘書は画面を離れているあいだも、最大2時間ぶんまで少し稼ぐ。
- まとまった円は伝説入りで名声に変える。名声は消えず、収入の底が上がる。金と強化はリセットされる。

記録はこのブラウザの中だけに残る。最初からにするには店の「記録を消す」か、`?reset=1` を付ける。

## 起動

コマンドは、このゲームのフォルダの中で実行する。`C:\Users\あなた` のようなホームでは `package.json` が無く、npm はすぐ止まる。

まだ手元に無い場合は、先にこのブランチを取る。

```bat
cd /d %USERPROFILE%
git clone --branch cursor/infinite-swipe-game-bf45 https://github.com/Mizukichi404/-PseudoMoneyGame.git
cd /d "%USERPROFILE%\-PseudoMoneyGame"
npm test
npm start
```

すでにクローンしてあるなら、そのフォルダへ移動してから同じ二つのコマンドを実行する。

```bat
cd /d "%USERPROFILE%\-PseudoMoneyGame"
npm test
npm start
```

`npm start` は Node だけで http://127.0.0.1:8765 を開く。表示された URL をブラウザで開く。止めるときはそのウィンドウで Ctrl+C。
